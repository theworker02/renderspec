# renderspec

Render encode/decode helpers for spec payloads in pipelines.

**Site:** https://theworker02.github.io/renderspec/

## Install / run

```bash
git clone https://github.com/theworker02/renderspec.git
cd renderspec
node src/cli.js
node --test
```
